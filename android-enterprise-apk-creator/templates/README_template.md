adb install app/build/outputs/apk/debug/app-debug.apk

### Release APK
1. Generate keystore: keytool -genkey -v -keystore my-release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias my-alias
2. Configure signing in app/build.gradle
3. Build: ./gradlew assembleRelease
